# SWIGGY SALES DATA REPORT

## Overview
This report analyzes Swiggy's sales and order trends using SQL queries. It utilizes multiple tables to extract meaningful insights.

## Data Sources
The report is generated using the following tables:
- **Customers ** - Contains customer details.
- **Orders ** - Stores order-related information.
- **Restaurants ** - Holds restaurant data.
- **Deliveries ** - Tracks delivery details.
- **Riders ** - Contains information about delivery personnel.

## Key Insights & Queries
1. **Year & Weekday with Highest Average Orders**
2. **Gender-wise Total Completed Orders (All Years)**
3. **Monthly-wise Total Completed Orders on a Yearly Basis**
4. **Top 5 Restaurants with Highest Revenue**
5. **Top 5 Cuisines with Highest Orders**
6. **Top 5 Riders with Most Deliveries**
7. **Top 5 Fastest Riders (Lowest Average Delivery Time)**
8. **Delivery Time Trends by Time Slot (Morning, Afternoon, Evening, Night)**
9. **Top 3 Restaurants with Highest Order Cancellations**
10. **Percentage of Different Order Status in Total Orders**
11. **Yearly Quarter-wise Cumulative Revenue**

## Usage
The SQL queries in this report can be used to gain insights into Swiggy's order and delivery patterns. These queries help in understanding customer behavior, restaurant performance, and rider efficiency.
